# SHOP API

## 1. Краткое описание проекта

Данный проект - это REST API интернет-магазина продуктов на Django Rest Framework с поддержкой категорий, подкатегорий, товаров, корзины, токен-авторизации, Swagger-документацией и автотестами.
Функционал через административную панель Django:
   - создание, редактирование и удаление категорий и подкатегорий;
   - добавление, редактирование и удаление продуктов.

Функционал через эндпоинты:
   - вывод всех категорий с вложенными подкатегориями;
   - вывод продуктов;
   - добавление, изменение количества и удаление продукта в корзине (каждый пользователь работает только со своей корзиной);
   - вывод состава корзины с подсчётом общего количества товаров, общей стоимости товаров;
   - полная очистка корзины.

### Прочее
   - авторизация по токену;
   - фикстуры для быстрого наполнения БД тестовыми данными;
   - Swagger-документация API;
   - автотесты (покрыты несколько GET и POST методов).

## 3. Установка и запуск
Проект можно запустить двумя способами: **локально** (без Docker) или через **Docker Compose** (рекомендуется).

### Локальный запуск (без Docker)
#### 1. Клонирование репозитория
```
git clone https://github.com/GrigoriyNikitin/Sarafan_and_Dokt24_services.git
cd Sarafan_and_Dokt24_services
```
#### 2. Создание и активация виртуального окружения
```
python -m venv venv
venv\Scripts\activate
```
#### 3. Установка зависимостей
```
pip install -r requirements.txt
```
#### 4. Применение миграций
```
python manage.py makemigrations
python manage.py migrate
```
#### 5. Загрузка фикстур
```
python manage.py load_fixtures
```

#### 6.  Запуск сервера разработки
```
python manage.py runserver
```
Административная панель приложения будет доступна по адресу: http://127.0.0.1:8000/admin/


### Запуск через Docker Compose
#### 1. Клонирование репозитория
```
git clone https://github.com/GrigoriyNikitin/Sarafan_and_Dokt24_services.git
cd Sarafan_and_Dokt24_services
```
#### 2. Создание .env файла
Скопируйте пример и при необходимости отредактируйте значения:
```
cp .env.example .env
```
#### 3. Сборка и запуск контейнеров
```
docker compose up --build -d
```
Применение миграций и загрузка фикстур выполнятся автоматически.
Административная панель приложения будет доступна по адресу: http://127.0.0.1:8000/admin/


## 4. Документация Swagger
После запуска сервера документация (в которой описаны доступные эндпоинты и структура запросов/ответов) доступна по адресам:
```
Swagger UI: http://127.0.0.1:8000/api/swagger/
ReDoc: http://127.0.0.1:8000/api/redoc/
```

## 5. Запуск тестов
Для запуска тестов необходимо выполнить следующую команду:
```
pytest -v
```
